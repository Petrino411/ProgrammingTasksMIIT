# ProgrammingTasksMIIT

Лабораторные и практические работы по программированию за несколько семестров РУТ (МИИТ):
C, C++ (STL и ООП с тестами на GoogleTest), C#, отчёты и схемы.

## Зачем

Это архив учебных заданий, а не один продукт: каждая папка — отдельная работа со своим `main`,
своей сборкой и, где требуется, тестами. Удобно как справочник «как я решал такие задачи».

## Что где лежит

| Папка | Содержимое |
|-------|-----------|
| `CLang/` | 12 задач на C: вычисления и функции (`Task1_*` — формулы, байты в мегабайты, сопротивление резисторов), ветвления и перечисления (`Task2_*`), циклы и суммы с точностью (`Task3_*`), массивы и матрицы (`Task4_*` — обработка элементов, удаление по условию, матрица n×m). У каждой задачи `.c` + проект MSVC `.vcxproj` |
| `Term_3/Task_2` | C++: «овощной магазин» — классы `Vegetable`, `Record`, `Shop`, подсчёт прихода за период; тесты GoogleTest |
| `Term_3/Task_4_2_new` | C++: библиотека `Matrix`, генераторы значений и упражнения над матрицей; тесты GoogleTest |
| `Term_4/` | STL: обработка файлов итераторами, удаление элементов из контейнера, статистика слов, сортировка структур (C++20, CMake) |
| `Term_5/SortAlgs` | C#: пузырьковая, вставочная и быстрая сортировки на 100 000 элементов в отдельных потоках, сравнение по числу сравнений |
| `OOP_C++/` | четыре работы по ООП: класс `Person`, `Point`/`Cylinder`, пикетаж и ограничение скорости (`Task_3`), стек (`Task_4`); у `Task_3` и `Task_4` сборка с GoogleTest |
| `Reports/` | отчёты по работам в `.docx` |
| `Cringe_schemas/` | схемы и таблицы (`.drawio`, `.xlsx`) |

## Сборка

C-работы рассчитаны на MSVC: открыть `TasksCPP.sln` в Visual Studio или собрать конкретный
`.vcxproj`. Часть задач использует `corecrt_wctype.h`, поэтому вне Windows они не собираются.

C++-работы собираются CMake (проверено на `Term_4/Task1`):

```
cmake -S Term_4/Task1 -B build
cmake --build build
```

`OOP_C++/Task_3` и `OOP_C++/Task_4` подключают GoogleTest подмодулем — перед первой сборкой:

```
git submodule update --init --recursive
```

`Term_3` подтягивает GoogleTest сам через `FetchContent` (нужен доступ в сеть).

C#-работа:

```
dotnet run --project Term_5/SortAlgs/SortAlgs
```

## Ограничения

* Общего решения для всего репозитория нет: `TasksCPP.sln` собирает только работы на C, остальные
  папки независимы.
* Задачи на C писались под MSVC (в том числе заголовок `corecrt_wctype.h`), кроссплатформенности нет.
* В отчётах есть номера вариантов и данные задания — это учебный архив, а не готовый шаблон.
